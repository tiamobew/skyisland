# Sky Island — เกมกระดานผจญภัย 3D

เกมกระดานบนเกาะลอยฟ้า สำหรับผู้เล่น 2–4 คน ตอบโจทย์ทศนิยมให้ถูกเพื่อทอยลูกเต๋าและเดินหมากไปยังเส้นชัย

กระดานมี 40 ช่อง ลูกเต๋าออกได้ 1–3 แต้ม และมีกล่องลึกลับสีแดง 8 กล่องวางชิดพื้นในตำแหน่งใหม่แบบสุ่มทุกเกม เมื่อหยุดบนกล่องจะแสดงสายรุ้งพร้อมเสียง ให้ผู้เล่นกดสุ่มดวงเพื่อหมุนวงล้อเดินหน้า 1–4 ช่อง โดยทุกผลลัพธ์มีโอกาสเท่ากัน

เกมแบ่งโจทย์เป็น 3 ด่าน ได้แก่ จำนวนนับ ทศนิยม และร้อยละ แต่ละด่านเลือกระดับง่าย ปานกลาง หรือยากได้ หน้า Admin รองรับการเพิ่ม ลบ แก้ไข และนำเข้าไฟล์ CSV/JSON แยกตามด่านได้มากกว่า 100 ข้อ

## คลังโจทย์ CSV ออนไลน์

เกมโหลดคลังโจทย์ล่าสุดจากไฟล์ต่อไปนี้ทุกครั้งที่เปิดหน้า และใช้ข้อมูลเดิมในอุปกรณ์เป็นตัวสำรองเมื่อออฟไลน์

- `data/counting.csv` — ด่าน 1 จำนวนนับ
- `data/decimal.csv` — ด่าน 2 ทศนิยม
- `data/percent.csv` — ด่าน 3 ร้อยละ

หน้า `admin.html` รองรับการนำเข้า CSV/JSON และดาวน์โหลด CSV แยกด่าน หากต้องการอัปเดตโจทย์ให้ผู้เล่นทุกอุปกรณ์ ให้แทนไฟล์ CSV ในโฟลเดอร์ `data` แล้วเผยแพร่เว็บไซต์อีกครั้ง

## โครงสร้าง

- `index.html` — หน้าเกมหลัก
- `admin.html` — จัดการคลังโจทย์ของเกม
- `css/style.css` — รูปแบบหน้าจอเกม
- `js/` — ระบบกระดาน ตัวละคร ลูกเต๋า เสียง และคลังโจทย์
