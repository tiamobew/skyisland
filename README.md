# Sky Island — เกมกระดานผจญภัย 3D

เกมกระดานบนเกาะลอยฟ้า สำหรับผู้เล่น 2–4 คน ตอบโจทย์ทศนิยมให้ถูกเพื่อทอยลูกเต๋าและเดินหมากไปยังเส้นชัย

กระดานมี 40 ช่อง ลูกเต๋าออกได้ 1–3 แต้ม และมีกล่องลึกลับวางแบบสุ่ม เมื่อหยุดบนกล่องจะหมุนวงล้อเพื่อเดินหน้าหรือถอยหลัง 1–5 ช่อง โดยทุกผลลัพธ์มีโอกาสเท่ากัน

เกมแบ่งโจทย์เป็น 3 ด่าน ได้แก่ จำนวนนับ ทศนิยม และร้อยละ แต่ละด่านเลือกระดับง่าย ปานกลาง หรือยากได้ หน้า Admin รองรับการเพิ่ม ลบ แก้ไข และนำเข้าไฟล์ JSON แยกตามด่านได้มากกว่า 100 ข้อ

## โครงสร้าง

- `index.html` — หน้าเกมหลัก
- `admin.html` — จัดการคลังโจทย์ของเกม
- `css/style.css` — รูปแบบหน้าจอเกม
- `js/` — ระบบกระดาน ตัวละคร ลูกเต๋า เสียง และคลังโจทย์
