# Sky Island — เกมบันไดงู 3D

เกมกระดานบันไดงูบนเกาะลอยฟ้า สำหรับผู้เล่น 2–4 คน ตอบโจทย์ทศนิยมให้ถูกเพื่อทอยลูกเต๋าและเดินหมากไปยังเส้นชัย

กระดานมี 40 ช่อง ลูกเต๋าออกได้ 1–3 แต้ม และมีทางลัดกับกับดักแบบบันไดงูบนเส้นทาง

## เล่นออนไลน์

https://tiamobew.github.io/skyisland/

## โครงสร้าง

- `index.html` — หน้าเกมหลัก
- `admin.html` — จัดการคลังโจทย์ของเกมบันไดงู
- `css/style.css` — รูปแบบหน้าจอเกม
- `js/` — ระบบกระดาน ตัวละคร ลูกเต๋า เสียง และคลังโจทย์

เกมผจญภัยทศนิยมถูกแยกไปที่ repository `Adventure`:
https://github.com/tiamobew/Adventure
